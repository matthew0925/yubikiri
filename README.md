# ゆびきり

フリーランス・個人事業主向け、受注条件・納品記録の改ざん防止アプリの企画叩き台。
（旧案名「タシカニ」から改名）

## アプリ名の由来
「指切りげんまん」の指切り。子供の頃の約束の儀式を、大人の商取引に転用する皮肉と温かみ。
「証拠アプリ」的な硬さではなく、口約束が破られる痛みという、このアプリが解決する感情そのものを名前にした。

## 中身
- `ゆびきり_技術仕様書.md` — プロダクト概要、ネーミング・アイコンの意図、法的ポジショニング、MVPスコープ、iOS/Android実装方針（OpenTimestampsによるブロックチェーンアンカリング含む）、マネタイズ、開発ロードマップ、リスク評価
- `aso-materials.md` — App Store掲載用の名称・説明文・キーワード・スクリーンショット構成案
- `icon.svg` — アイコンのベクターコンセプト（赤い糸と小指のシルエット）
- `aso-screenshots-draft/` — スクリーンショット下書き用フォルダ（未作成、実装後に追加）

## 位置づけ
「そっと（Sotto）」「ミセルダケ」に続く、個人開発の買い切り型スマホアプリ企画の3本目の叩き台。
サーバーレス（OpenTimestampsという無料の公開インフラのみに依存）・買い切り＋機能差フリーミアムを採用。
