プライバシーポリシー

ゆびきり（iOSアプリ）／最終更新日：2026年8月20日

「ゆびきり」（以下「本アプリ」）は、開発者（以下「当方」）が提供するiOSアプリケーションです。本ポリシーは、本アプリがどのような情報を扱うかを説明するものです。

基本方針

本アプリは自社サーバーを持たず、ユーザーが入力した案件名・クライアント名・記録内容・添付画像などの個人情報や業務データは、すべてお使いの端末内にのみ保存されます。当方を含む第三者がこれらのデータをサーバー等で収集・閲覧することはありません。

端末内にのみ保存される情報（当方には送信されません）

  • 案件名、クライアント名
  • 記録の本文、金額、納期
  • 添付したスクリーンショット等の画像
  • 上記から計算されたSHA-256ハッシュ値

これらは端末の暗号化されたストレージ（NSFileProtectionComplete）に保存され、バックアップのエクスポートを除き、ユーザー自身の操作なしに端末外へ出ることはありません。

外部サービスに送信される情報

  • OpenTimestamps（有料機能を利用した場合のみ）：記録内容から計算したSHA-256ハッシュ値（32バイトの数値）のみを、公開の無料インフラであるOpenTimestampsのカレンダーサーバーへ送信します。ハッシュ値から元の記録内容を復元することはできません。記録の本文・画像そのものが送信されることはありません。
  • Apple（StoreKit）：アプリ内課金（買い切り）の決済処理はApple社のStoreKitを通じて行われ、支払い情報は当方には一切共有されません。

端末の機能へのアクセス

  • 写真ライブラリ：記録に添付する画像を選択する際にのみ使用します。当方のサーバーへのアップロードは行いません。
  • Face ID / Touch ID / パスコード：アプリロック機能（任意設定）で、端末の生体認証・パスコード機構を利用します。認証情報自体はAppleのセキュアな仕組み内で処理され、当方が取得・保存することはありません。

情報の第三者提供

当方は、ユーザーの個人情報や記録データを第三者に提供・販売することはありません。上記「OpenTimestamps」「Apple（StoreKit）」への送信は、機能を実現するために必要な最小限の情報（ハッシュ値のみ、または決済処理そのもの）に限られます。

分析・広告

本アプリは、広告表示や第三者アナリティクスSDK（行動追跡等）を組み込んでいません。

データの削除

本アプリをアンインストールすると、端末内に保存された全ての記録データは削除されます。当方のサーバーにはデータが存在しないため、削除依頼のご連絡は不要です。

お子様のプライバシー

本アプリは業務利用者（フリーランス・個人事業主）を対象としており、13歳未満のお子様の利用を想定していません。

本ポリシーの変更

本アプリの機能追加等に伴い、本ポリシーを改定することがあります。重要な変更がある場合は、アプリ内または本ページにてお知らせします。
